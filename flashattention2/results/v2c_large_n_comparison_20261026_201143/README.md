# 原 V2c 与 Bc=32/Q 常驻寄存器：大 N 对照

RTX 4070 Ti SUPER，66 SM；Br=64、D=64、128 threads/block。
原版 Bc=64，新版 Bc=32 且 Q fragments 常驻寄存器。
NCU 2026.3.1；--clock-control none --cache-control all。
三个 N 各三轮，每轮随机 N 顺序，同一 N 内随机两版本顺序。表中为三轮中位数。
**未外部锁频，以下是 NCU profiling 耗时，不是 CUDA Graph benchmark。**

| N | 原 V2c ms | 新版 ms | 耗时降低 | 原 occupancy | 新 occupancy |
|---:|---:|---:|---:|---:|---:|
| 16384 | 1.112864 | 1.023232 | 8.05% | 15.44% | 27.06% |
| 32768 | 4.681536 | 3.886272 | 16.99% | 15.89% | 34.46% |
| 65536 | 17.436160 | 15.946176 | 8.55% | 16.27% | 38.11% |

## 三轮耗时范围

| N | 原 V2c ms | 新版 ms |
|---:|---:|---:|
| 16384 | 1.112672–1.361408 | 1.001984–1.028320 |
| 32768 | 4.666656–4.685216 | 3.808224–4.195872 |
| 65536 | 17.420480–17.500000 | 15.867232–16.531712 |

各尺寸资源一致：原版 40 KiB shared、96 registers/thread，新版 16 KiB、96 registers/thread。
理论 occupancy 分别为 16.67% 和 41.67%。
本轮每个配对样本中新版均更快；N=16384 原版第二轮有明显耗时波动，不能将中位数比例视为严格定频收益。
增大 N 后新版实际 occupancy 更接近理论值，但耗时收益不随 occupancy 增幅成比例。
本实验联合比较 Bc 缩小与 Q 缓存，不拆分两项改动各自贡献。

源码及可执行文件在采集前后的 SHA256 一致。manifest.json 含完整命令和原始数值；
18 份 .ncu-repz 为原始报告；summary.json 为统计结果；telemetry.csv 为频率遥测。
run_compare.py 为采集脚本，重跑需使用新的空结果目录以保留原始数据。
